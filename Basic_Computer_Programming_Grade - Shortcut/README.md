# Basic Computer Programming - Grade Calculator

โปรแกรม GUI สำหรับรวมคะแนนและตัดเกรดนักศึกษา 20 คน
รายวิชา Basic Computer Programming

## คะแนน

- Midterm = 50 คะแนน
- Final = 50 คะแนน
- Total = 100 คะแนน

## เกณฑ์ตัดเกรด

| คะแนน | เกรด |
|---|---|
| 80–100 | A |
| 75–79 | B+ |
| 70–74 | B |
| 65–69 | C+ |
| 60–64 | C |
| 55–59 | D+ |
| 50–54 | D |
| 0–49 | F |

## ความสามารถของโปรแกรม

1. แสดงนักศึกษา 20 คน
2. แก้ไขชื่อนักศึกษาได้
3. กรอก/แก้ไขคะแนน Midterm และ Final ได้
4. คำนวณคะแนนรวมอัตโนมัติ
5. ตัดเกรด A ถึง F
6. แสดงค่าเฉลี่ย
7. แสดงคะแนนสูงสุดและต่ำสุด
8. แสดงจำนวนผู้ผ่าน
9. ล้างคะแนน
10. บันทึกผลเป็น CSV

## วิธีรันใน VS Code

เปิดโฟลเดอร์นี้ใน VS Code แล้วเปิด Terminal จากนั้นใช้:

```bash
python main.py
```

โปรแกรมใช้ Tkinter ซึ่งมากับ Python โดยปกติ จึงไม่จำเป็นต้องติดตั้ง package เพิ่ม
